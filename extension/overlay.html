Add this to OBS in 30 seconds

  1. Keep this window open (don't minimize it).
  2. In OBS: Sources → + → Window Capture and pick this window.
  3. With the green background: right-click the source → Filters → + → Chroma Key. Default settings work.
  4. Drag and scale it into your scene — done. Numbers update live as you trade.
Tip: if your scene has a lot of green in it, switch the background to Magenta and set the Chroma Key filter's key color to match. This toolbar only shows when your mouse is over the window — it never appears on stream.
