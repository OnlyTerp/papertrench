Verifiable leaderboard

A leaderboard that can't be faked

Every fill is committed to a SHA-256 hash chain the moment it happens — before the outcome is known. No inserting trades, no deleting losers, no backdating winners. The dashboard re-derives your record from the chain and standings are recomputed server-side from the raw fills, never from a self-reported number.

⛓️

Tamper-evident by construction

Each fill commits to the hash of the previous one. Touch anything, and every link after it breaks.

🔍

Every price re-verifiable

Fills record mint, price, and timestamp — so a verifier can re-check them against real market history.

🪪

Verified identity

One ranked record per verified account, making sybil entries expensive.

30-second install

In the trenches in half a minute

Not on the Chrome Web Store yet — loading it unpacked is quick.

01

Download

Open the latest release, grab the papertrench-*.zip under Assets, and unzip it.

02

Open extensions

Go to chrome://extensions and flip on Developer mode.

03

Load unpacked

Select the folder containing manifest.json.

04

Trade

Open any supported token page — the overlay appears within seconds.

Updating later? Unzip the new release over the same folder you already loaded (overwrite the files), then hit ↻ Reload on the extension card. Your wallet, history, and attest chain all live with the folder — a brand-new folder starts a blank wallet. You can also back up from the extension popup any time.
