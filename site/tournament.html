✂ Eliminations
§ How a tournament worksReference
  1. One verified chain, the same stack.

    The server reads each entrant's existing verified chain and scores only rounds inside the tournament window. ROI is scaled to the same starting stack for display; no separate book is created and the main-board record is not modified.

  2. The clock is the server's.

    Rounds are fixed windows folded from the tournament's start time — 24 hours by default. When a boundary passes, the cron settles it once, freezes the standings it decided from (hash and all), and cuts the bottom of the board. A boundary can never be re-run or talked into a different result.

  3. The bottom five fall, every round.

    Ranking uses ROI from the same server-verified windowEntry as the other boards; the displayed P&L scales that ROI to the common tournament stack. A cut waits 15 minutes for a post-boundary verified chain. No verified final entry is a forfeit, ranked below every final entry. When the survivors number no more than the cut, that round crowns instead of cutting.

  4. Spectating is data, not video.

    Click any trader on the board to see their verified window return and open positions. Open bags are marked from independent candles at the current bell; if a candle is missing, the row says so and uses gross cost.
